    议程

    🗓️ 议程¶

    从一份设计文档出发，借助 Autopilot 和编码智能体，一路完成需求、测试用例、测试集和执行。中间有两次休息和一次午餐。

    环境准备不占用课程时间

    请在课程开始前完成环境准备页面的全部内容，包括在 Studio 中登录 UiPath staging，以及准备好你的 UiBank 测试用户。课程中没有时间安装 Studio 或技能。

    👋 欢迎¶

    👋 欢迎、自我介绍，以及当天的安排 演示

    💡 1. 简介 + 理论知识¶

    💡 简介 + 理论知识：UiPath Test Cloud 和 Test Manager、Autopilot for Testers、Autopilot for Developers、使用 uip CLI（命令行）和 UiPath skills（UiPath 技能）的编码智能体，以及各自适用的场景 演示 + 现场 Demo

    🙌 2. 动手实践¶

    打开 Studio 和 Test Manager：简介结束后马上进入动手实践环节。

    ⚙️ 环境准备¶

    在 Test Manager 中创建新项目（例如项目名称 {YourName}_UIB_Test，前缀 UIB） 动手实践

    在 Studio 中创建新的测试自动化项目，并将其连接到 Test Manager 动手实践

    📋 需求¶

    打开 Studio 和 Test Manager，让 Studio Desktop 中的 Autopilot 创建需求，来源是那份 .docx 文档 动手实践

    在 Test Manager 中讨论生成的需求 讨论

    用 Test Manager 中的 Autopilot 评估需求质量，落实部分建议，然后重新评估 动手实践

    ☕ 休息¶

    🧪 测试用例¶

    让 Test Manager 中的 Autopilot 创建测试用例，针对某一条具体需求 动手实践

    🍽️ 午餐¶

    离开屏幕歇一歇。如果你的编码智能体还在构建，就让它边跑着，你边吃饭。

    🙌 2. 动手实践（续）¶

    🧪 测试用例（续）¶

    在 Studio 中手动实现 Login 测试用例 动手实践

    让 Studio Desktop 中的 Autopilot 或 Codex 生成一个测试用例，在 Studio Desktop 中完成 动手实践

    在 Test Manager 中自主运行一个测试用例，并实时观看运行过程 动手实践

    再实现几个测试用例 动手实践

    ☕ 休息¶

    ▶️ 执行¶

    探索 Test Manager 中的 Executions（执行）选项卡 动手实践

    📦 测试集¶

    发布你的测试项目到租户源 动手实践

    让 Studio Desktop 中的 Autopilot 创建测试集，基于已有的测试用例 动手实践

    运行测试集 动手实践

    查看测试集的执行情况 动手实践

    如何让这一天顺利进行

    • 安排是灵活的。工作坊期间我们可以随时调整，包括休息时间。
    • 智能体构建的时间，就是你审阅的时间。Autopilot 或编码智能体工作时，读一读它正在生成的内容，或者提前看看下一个选项卡。
    • 休息时间也是追赶进度的时间。如果休息开始时你的编码智能体还在构建，就让它继续跑，你先去休息。
    • 测试集有备用方案。讲师会在共享文件夹中发布 DemoUiBankTests 包。如果你自己的测试用例没能及时完成自动化，创建和运行测试集时就用讲师的包——你照样可以运行测试集并查看它的执行情况。
