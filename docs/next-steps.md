# 🚀 后续步骤 { #next-steps }

!!! tip "你已完成整个工作坊"

    从配置 `uip` CLI（命令行）开始，你一路把一份设计文档变成了需求、测试用例，以及在 Test Cloud 中执行完毕并生成报告的测试集——而编码智能体全程在你身边承担构建工作。

## 🔁 继续测试 { #keep-testing }

- 用同样的三个实验去测你自己的应用：换掉设计文档，提示词保持不变。
- 添加反向测试用例，例如转账金额超过余额、贷款期限无效等，并把它们加入你的测试集。
- 让更多测试用例实现数据驱动，使一个测试用例可以用多组数值运行。
- 换一个编码智能体（Cursor、Codex），搭配同样的 UiPath skills（UiPath 技能）试试看。
