## 📝 反馈 { #feedback }

告诉我们哪些地方做得好，哪些地方还可以改进。

!!! info "如何让这一天顺利进行"
    - **安排是灵活的。**工作坊期间我们可以随时调整，包括休息时间。
    - **智能体构建的时间，就是你审阅的时间。**Autopilot 或编码智能体工作时，读一读它正在生成的内容，或者提前看看下一个选项卡。
    - **休息时间也是追赶进度的时间。**如果休息开始时你的编码智能体还在构建，就让它继续跑，你先去休息。
    - **测试集有备用方案。**讲师会在共享文件夹中发布 `DemoUiBankTests` 包。如果你自己的测试用例没能及时完成自动化，创建和运行测试集时就用讲师的包——你照样可以运行测试集并查看它的执行情况。
